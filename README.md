# Modern Python UI Application

A clean, professional GUI application built with Python and tkinter featuring a modern design and multiple functional tabs.

## Features

### 🏠 Dashboard
- Welcome screen with overview
- Quick action buttons
- Statistics cards showing current activity
- Real-time clock display

### 📋 Task Manager
- Add, complete, and delete tasks
- Task status tracking (Pending/Completed)
- Creation timestamp for each task
- Clear all tasks functionality

### 📁 File Manager
- Open and view text files
- Save application data to JSON
- Load previously saved data
- Text content display with scrolling

### 🧮 Calculator
- Basic arithmetic operations (+, -, ×, ÷)
- Percentage calculations
- Clear and sign change functions
- Clean, button-based interface

## Installation

1. Make sure you have Python 3.6+ installed
2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:
```bash
python main.py
```

## Interface Overview

- **Modern Design**: Clean, professional appearance with consistent styling
- **Tabbed Interface**: Easy navigation between different features
- **Responsive Layout**: Adapts to window resizing
- **Status Bar**: Shows current application status and real-time clock
- **Keyboard Shortcuts**: Enter key support for task entry

## Technical Details

- Built with Python's tkinter library
- Uses ttk (themed tkinter) for modern widget styling
- Custom color scheme and typography
- JSON-based data persistence
- Error handling for file operations

## Requirements

- Python 3.6+
- tkinter (usually included with Python)
- Optional: Pillow for enhanced image support

The application is fully self-contained and ready to run immediately after installing the dependencies.
